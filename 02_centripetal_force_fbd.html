Centripetal Force & Free-Body Diagrams

1. What “centripetal force” means

Centripetal force is not an extra kind of force. It is the name for the net inward radial force required to produce circular acceleration.

ΣFinward = mac = mv²/r

The inward force may be supplied by tension, friction, gravity, a normal force, or components of several forces.

2. The most important method

  1. Draw a free-body diagram of the object only.
  2. Include actual forces: gravity (mg), normal force (N), tension (T), friction (f), etc.
  3. Choose a radial axis pointing toward the circle's center.
  4. Write Newton's second law along that axis: ΣFradial = mv²/r.
  5. Write a separate equation for any perpendicular direction if needed.
Do not draw “centripetal force” as an additional arrow. Identify which real forces add up to the inward net force.

3. Common situations

Horizontal circle: object on a string / model plane

If tension is the only horizontal inward force:

T = mv²/r

If speed doubles while m and r stay fixed, tension becomes four times as large.

Car turning on a flat road

Static friction supplies the inward force:

fs = mv²/r

At the threshold of slipping, fs,max = μsN. On a level road N = mg, so:

μs,min = v²/(rg)

More speed or a tighter turn requires more friction. If required friction exceeds the maximum available static friction, the car skids.

Conical pendulum

A mass on a string moves in a horizontal circle while the string makes angle θ with the vertical. Resolve tension:

T cosθ = mg
T sinθ = mv²/r

The horizontal component provides centripetal force; the vertical component balances weight. If the string length is L, circle radius r = L sinθ.

4. How to choose signs

It is often easiest to define “toward the center” as positive. A force pointing inward is positive; one pointing outward is negative. The net radial force must point inward for circular motion.

5. Frequent mistakes

  • Using ΣF = mv²/r in every direction. It applies only along the radial direction; tangential acceleration may be zero in uniform circular motion.
  • Assuming tension always equals mv²/r. Other forces may contribute radially.
  • Confusing static friction with kinetic friction. A tire rolling without slipping generally uses static friction.
  • Assuming an object at rest has no static friction. Static friction can act whenever needed to prevent relative slipping.
  • For a flat turn, forgetting N = mg before substituting fs,max = μsN.

6. Mini examples

Model plane: m = 0.90 kg, v = 19 m/s, r = 2.0 m. T = mv²/r = 0.90(361)/2 = 162.5 N.

Car: v = 8.0 m/s, r = 9.0 m. μs,min = 64/(9×9.8) = 0.73 (approximately; use the g value your class uses).
